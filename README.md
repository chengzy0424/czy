# 程子悦的 Unity 游戏客户端开发作品集

公开主页：https://chengzy0424.github.io/czy/

## 页面

- `index.html` 为 Unity 定向求职主页：个人信息、Ash Exodus《清理者行动》和 Echo of Ruin《残响墟境》两款代表游戏、技术拆解、其他四款 Unity 项目、实习与教育经历、影像入口及联系方式。
- `exhibition.html` 保留原来的三维创意展厅，包括骨骼画廊、机械装置、蜂巢与粒子下潜。展厅内可返回求职主页。
- 六部 AE 影像、三部 AIGC 短片及全部六款游戏均保留。主页指向 AE/AIGC 的链接会直接选择对应作品分类。
- 原主页的 `#lab`、`#machine` 等空间章节及 `?scene=...` 链接继续指向保留的展厅。

## 内容依据

求职方向为 Unity 游戏客户端开发。教育信息、实习日期及职位依据用户提供的游戏方向简历；学校名称按用户要求不展示。下载按钮提供用户现有的游戏方向 PDF。

两款主项目由用户确认独立开发，使用部分第三方场景及美术资源，部分场景资产来自爱给网。主页使用现有录屏提取的实机图，去除录屏边缘的编辑器栏，保留游戏内画面和 HUD。其他项目的概念封面有文字说明。

技术拆解经过游戏工程脚本只读核对：

- Ash：`CPBallistics` 中的有限速度弹道、时间子步、位移扫掠、玻璃破坏与伤害衰减、射击记录回收；`CPEnemy.ObstacleTraversal` 中的障碍处理与导航衔接。
- Echo：`EchoActor`、`EchoFeiyuanTiming` 与 `EchoWeaponClearance` 中的输入缓冲、动作窗口、攻击有效帧、刀刃扫掠及命中去重。

未将游戏工程或完整游戏源码发布到本仓库。网站文案说明实际实现，不包含未经测量的性能提升数字。

## 开发与构建

源码位于 `portfolio-source`。在该目录安装锁定依赖后执行 `npm run dev` 或 `npm run build`。Vite 同时构建主页和展厅，输出到 `release-lab`。

- `src/recruit.js` 与 `src/recruit.css` 管理求职主页。
- `src/main.js`、`src/space*.js` 等继续管理原展厅。
- `src/portfolio.js`、`src/stream-player.js` 和媒体目录由两页共享。
- `public-recruit/art/recruit` 保存响应式实机图片，`public-recruit/resume` 保存已提供的简历。
- 旧有的 `art`、`media` 与 `licenses` 是根目录共享资源，开发服务器对未包含在当前源码构建中的共享资源转到已发布站点。

将 `release-lab` 中的新增和更新文件复制到仓库根目录发布；保留既有共享媒体。不要将 Unity 工程、原始视频、Library 或桌面目录复制到发布产物。

## 加载与视频

默认主页不导入 Three.js、空间渲染器或环境贴图。首屏先显示文本和静态实机图；视频在播放操作时创建，意图预热只准备对应播放器与首段。进入展厅才加载三维资源。

沿用已有 HLS 自适应播放器和 15 部视频的媒体清单，保留手机弱网档位、Safari 原生 HLS、失败重试、兼容播放和关闭时的资源释放。浏览器检查说明已测环境中的行为，不承诺所有设备和网络下均无等待。

## 验证

回归检查覆盖展厅几何、连续镜头、媒体清单、弱网播放策略、分类切换与弹窗释放。新版另检查了代表作预览的鼠标和键盘切换、六款游戏实际播放、AE/AIGC 入口、简历下载一致性、主页与展厅往返、旧章节链接及桌面/平板/手机布局。
