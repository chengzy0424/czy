# 视觉实现与参考边界

本轮以用户明确指定的 Active Theory 录屏为方向；不启动随机主题，不回到海洋方案。Taste 与 finesse 的本次作用是检查构图、暗部、可读性、手机尺寸、交互反馈和动画静止时的完整画面。

实际看到：环形主体与交叉曲线；暖色聚集粒子；不规则中央装置；玻璃卡片的前后遮挡与变化透视；薄无衬线字；局部青绿/洋红反射。之前提供的同方向录屏还展示了红色机械结构和 THE LAB 蜂窝。

本项目实现：原创 ZY 环形实体、GPU 粒子、实例化晶体碎片、四张有厚度的三维卡片、连续且可逆的镜头路径。保留 HTML 导航和项目内容，兼顾招聘者直接阅读。鼠标局部偏转粒子并形成小幅镜头视差；卡片有悬停前移与边缘反馈；点击可返回原位置。

没有核实参考源代码。没有将抖音外层按钮或播放三角形复制进网站。没有用概念封面假称真实游戏截图。

差异仍在：原录屏徽标与本人的 ZY 不同；原中央装置包含更复杂的有机细节、光学折射与体积光；本项目优先保持实时性能和项目文字可读性。移动端缩减粒子与透明层级；不承诺与桌面视觉完全相同。

本轮修正：扁平 Z 改为有深度变化的连续管状曲线，环体加厚；两只低亮度半透明水母与稀疏定向流光服务于主体；手机中标志下降以避开姓名和入口。介绍段文字移到左下留白区，避免叠在环形反光上。玻璃表现采用虹彩反光和透明膜，去除额外的折射渲染，以降低首次绘制负担。

Taste 与 finesse 检查结合真实截图使用。保留用户明确选择的暗场、细边框及小型分类标签；通用检查器对这些风格提出的警告不是全部清零。其基于 DOM 的空白/动画统计无法完整评估 WebGL 画布，因此额外检查桌面、手机截图、真实视频播放、镜头连续性与减少动画模式。

复查入口：verification/oct30-release.json、verification/oct30-design-review.md，以及其中列出的浏览器截图。旧验证文件保留历史时间与结论，不代表当前版本。

## 2026-10-30 第二轮：形体、透视与章节衔接

本轮重新打开抖音原视频（7626063369507206760），实际查看了约 3 秒和 18 秒的网页画面；其余场景结合之前保存的参考录屏帧。登录提示影响了后续播放，本轮没有声称完整重看全部 72 秒。另查看公开作品集案例 7681253425706814783 的 8 秒、30 秒画面，只借鉴“前景运动、正文稳定”的组织方法，没有引入其纸张风格。参考截图仅作为本地对照资料，不随网站发布。

实际观察：参考的主体既有细边高光也有较宽的反光面；暖色粒子大小与密度不均匀；作品卡片前后错落，主卡文字居中，转动时仍能辨认相邻卡片。实现方式属于推测：可能结合程序几何、环境贴图和粒子着色器。未检查或复制参考网站源代码。

本轮修改：

- 环形主体与 ZY 曲线加厚，扩大环境反射光源，降低仅靠细亮边呈现的比例。
- 暖色粒子改为双向流动带，点尺寸与空间半径解耦；机械区粒子形成集中核心。桌面保持 44,000 点，手机 11,000 点，未通过盲目增加点数强化画面。
- 四张画廊卡片重新配置深度、位置、透明度和居中排版；滚动绕行时，软件卡片转向镜头，塔防卡片上移离开文字阅读区。
- 中央装置保留宽面折叠与实例化碎片；机械上下盖改为空心环，支柱与核心有前后遮挡；LAB 蜂窝沿曲面布置并增加真实深度。
- 章节间镜头提前注视下一处装置，保留横向绕行与深度变化，避免中段空场。路径由滚动位置决定，往返可逆。
- 手机移开按钮上方水母、隐藏被裁切的装饰英文；平板根据画幅后退相机，并将画廊说明移到左上留白；顶部导航增加不透明底，避免离场文字穿过品牌标志。
- 保留姓名、专业、方向、直达作品、联系方式与九部实际视频；元数据与演示说明的字号调至 13px。

判断与边界：这是沿指定视觉语言的原创个人作品集，不是逐像素克隆。原视频中的复杂光学折射、晶体微细节和部分体积光仍比当前实时程序模型复杂；本轮优先可读性、空间连续性与实际运行。没有使用 Blender、离线三维渲染或新环境图片。减少动态、播放时暂停背景、低性能自动降级和静态回退保持可用。

验证与审美检查：本轮浏览器回归、实际截图、性能条件与自动检查例外记录于 verification/oct30-refinement/。Taste/finesse 的通用“静止页面、空屏、无影片”等规则不能识别 WebGL 内部内容及按需播放，因此保留原始检查结果并以真实截图、滚轮输入与视频回归补充，不将检查结果描述为全部清零。

## 2026-10-30 第三轮：四张新截图的结构对照

用户要求沿新截图继续接近参考，不改身份和内容，也不回到海洋方案。本轮重新打开抖音视频 7626063369507206760，查看并保存了约 14 秒画廊、19 秒红色机械、22 秒蜂窝、25 秒红金流光的实际网页画面。登录弹窗反复出现，已通过页面关闭按钮处理；没有声称完整观看每一秒。浏览器栏、抖音字幕和播放器控件不进入作品集。

实际观察：第一张卡片宽度接近画面四成，左右前景卡之间露出分节、突出的脊柱结构；第二张出现向上倾斜退出的卡片和下方机械结构；第三张为横向反光面之下的褶皱金属蜂窝；第四张为较小徽标周围的大范围红金颗粒和发光带。具体模型构造、粒子模拟、材质着色器为本项目的实现判断，并非已取得参考源代码。

改动与原因：

- 将连续波纹圆柱替换成 19 个分离的三叉椎片、扫掠分支和交错链环。合并几何与实例化减少调用；缝隙和遮挡来自真实几何。
- 主要展板放大、分居左右前景；保持不同 Z 深度，退出时增加 X 轴翻转与轻微侧倾。透明背板适度加深，减少后方文字透叠。
- 画廊粒子从贴柱细线改成七组有密度变化的绕行团簇，点着色加入球面明暗和高光；桌面仍为 44,000 点，手机 11,000 点。
- 机械底部增加真实起伏的反光面；缩短章节间的世界坐标距离，并微调注视方向和距离，使前后结构能衔接进入视野。
- LAB 使用有倒角、厚度和各自朝向的实体六边形块，桌面 1,377 块、手机 703 块。表面具有多方向褶皱，标题与描述在桌面横向排列，手机保持独立阅读区。
- 蜂窝后增加录屏中的徽标/红金颗粒回归镜头：徽标缩小、交叉曲线转到上方、流光在后方运动。复用已有几何，不添加离线素材。
- 保留直接查看作品、减少动态、无 WebGL 回退、影片按需加载及播放时暂停背景。

当前仍有差距：参考的定制骨架更有机，玻璃有更复杂的折射/磨砂和细碎反射，红色流体更接近体积雾。本项目使用程序几何、透明表面和流动带重建这些视觉关系；没有将其描述为逐像素一致。徽标、项目封面和文字为程子悦的真实身份/作品，未用参考工作室项目冒充个人作品。

验证：8 项结构/交互测试通过；几何合计桌面 207,182、手机 139,766 个三角面（全世界总量，不等于每帧）；新桌面总预算 220,000，手机 170,000，增加预算用于实体蜂窝和新增镜头。单帧负担另以真实浏览器测量，未从总面数推断帧率。九部视频本地播放、关闭卸载、画质切换和背景暂停通过；多尺寸截图与实际滚轮/点击记录见本轮 verification/oct30-reference-match/。

Taste 与 finesse：已运行实际页面检查及构建引用检查。finesse 正式构建 P0 为 0。Taste 的静止/空屏报告无法观察 Canvas 内部三维运动；本轮保留这些原始报告，并以逐阶段实际截图补充。细边框、局部彩光和小型导航标签按用户指定参考保留；没有宣称通用美学警告全部消除。物理手机和其他浏览器仍未验证。
