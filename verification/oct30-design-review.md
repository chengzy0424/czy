## 实际观察、推测和原创实现

实际看到：暗背景、小型环形主体、细长交叉曲线、局部聚集的暖色粒子、左上红色钟形带触须形态、右上斜向亮线；中央不规则反射装置与有不同深度/角度的卡片相互遮挡，细无衬线字与小型边缘导航。此条参考所取片段没有完整展示红色机械室/蜂窝；这些章节沿用此前用户提供并检查过的同方向录屏结构。

推测：这些效果可由着色器、实例化与环境反射实现；没有检查参考网站源代码，不能当作其实际技术方案。

原创设计：保留程子悦的 ZY 身份和真实个人作品。Z 由扁平挤出体改为深度变化的连续曲线；加入两只低亮度水母、稀疏定向流光和可逆镜头路径。没有复制原站品牌或作品内容。

## 审美与性能检查

使用 Taste 与 finesse 辅助检查，结合 WebGL 实际截图审查。保留用户指定的暗场、细边框和小分类文字；通用风格告警没有全部清零。修复了手机入口与标志重叠、介绍文字压在高反光物体上、视频播放时画面被长列表推到下方的问题。

全部视频按需加载，播放时暂停背景；封面采用三档 WebP。异步场景构建、延迟画廊纹理、异步着色器编译减少首屏阻塞。去除了高成本的额外离屏折射渲染，保留虹彩反射与水母透明膜。

本地 1440×900 Edge 冷缓存、未限速的 12 秒观察中，文字首绘 28 ms、场景就绪约 241 ms、未记录到超过 50 ms 的主线程长任务。该数字是本地预览条件，不能当作公网或手机成绩。最终公网结果另列 release JSON。

游戏展示为实机录制的无声短片：塔防 26 秒、far cry 24 秒、Csol 22 秒、扫雷 18 秒。保持经典规则，没有编造游戏运行画面。三部 AE 和两部 AIGC 使用用户桌面提供的原片转码，原片未改动。BOE 没有新增未经确认可公开的界面。

网页游戏构建已从新发布树移除；Unity 工程本体保留。本地网页版副本的批量删除被自动审批拒绝，尚未释放对应空间；未重写 Git 历史。

## 公网复核

实现提交 e187def，GitHub Pages 部署成功。九个视频入口均实际播放并观察到进度前进；视频打开期间背景帧计数不变，关闭后播放器释放。五部影片均有两档画质资源，实际切换测试保持播放位置。14 个 MP4 的分段请求均返回 206；27 张封面成功获取；四个旧游戏网页均返回 404。320、390、768、1440 像素宽度检查没有横向溢出，手机尺寸触摸模拟可打开视频。

较长的《熟悉的陷阱》和《空格里的小镇》补查了约 10 秒连续播放与跳到结尾 4 秒的播放；不是全部影片从头到尾的全长测试。实体手机、Safari、不同网络尚未验证。

公网冷缓存单次测试：文字首绘 908 ms，三维场景就绪 1408 ms；出现一次 56 ms 主线程长任务。不得用本地 28 ms 首绘替代公网成绩，也不得宣称所有设备稳定 60 帧或没有卡顿。
